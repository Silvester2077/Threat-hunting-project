## Project Goal

Build an incremental threat-hunting dossier on **Meduza Stealer**, an infostealer malware
family that spreads disguised as game cheats, cracked software and mods (Minecraft, CS2,
Roblox, etc.), applying each week's course concepts to a real, publicly-documented threat:

- **Week 1:** Cyber Threat Intelligence fundamentals — glossary + threat classification
  (financially-motivated infostealer, distribution via gaming community channels)
- **Week 2:** Data collection — OSINT gathering on Meduza Stealer samples and infrastructure
  (Shodan, VirusTotal, Maltego)
- **Week 3:** Data processing & exploitation — deploying MISP, importing and normalizing
  Meduza Stealer IOCs (hashes, C2 domains)

Each week's work is committed separately, with a short report and supporting evidence
(screenshots, exported data, scripts).
