## Project Goal

Build an incremental threat-hunting dossier on **APT29 (Cozy Bear)**, applying each week's
course concepts to a real, publicly-documented threat actor:

- **Week 1:** Cyber Threat Intelligence fundamentals — glossary + threat classification
- **Week 2:** Data collection — OSINT gathering on APT29 (Shodan, VirusTotal, Maltego)
- **Week 3:** Data processing & exploitation — deploying MISP, importing and normalizing APT29 IOCs

Each week's work is committed separately, with a short report and supporting evidence
(screenshots, exported data, scripts).
